What happens to your document

It is processed in memory on this server and discarded as soon as the results page is sent. Nothing is saved, and the document's content is never written to the server's logs.

What this version does

It splits a document into clauses using its structure: numbering, headings, labelled paragraphs and paragraph breaks. It does not yet flag risky clauses or explain them in plain language.
